# Keyword and TLD filters

The domain keyword search and the domain TLD selections. Part of the [SpamZilla filter reference](README.md), extracted from the supplied SpamZilla filter interface HTML; field names are preserved exactly as submitted by the form.

## Keyword Search

| Filter | Filter type | Visible field | Submitted/internal field | Notes |
|---|---|---|---|---|
| Domain keyword search | Text search | `keyword_search_xs` | `Filter[keyword]` | The visible search box populates the hidden form filter. |

## Major TLDs

### Major TLD selection

- **Filter type:** multi-select checkboxes
- **Field:** `Filter[tlds][]`
- **Options (5):**
  - `.com`
  - `.net`
  - `.biz`
  - `.info`
  - `.org`
